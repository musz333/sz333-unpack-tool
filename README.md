# sz333解压工具（sz333 Unpack Tool）

面向**分卷、多层嵌套、加密**资源包的 Windows 自动解压工具。
单个 exe，免安装，内嵌 7-Zip，双击即用。

## 它能做什么

- **分卷自动合并**：`partN` / `.NNN` / `.zNN` / `.rNN` 命名均可识别
- **按文件头魔数识别真实格式**：rar / zip / 7z / tar / gz / bz2 / xz / cab，自动改后缀循环解压（最多 30 层，可设置）
- **密码按序自动尝试**：密码列表在主界面直接管理，支持拖动排序；保存位置可选（注册表 / 密码列表.txt）
- **密码错误即时处理**：全部密码失败时弹窗输入正确密码并自动重试
- **工作流模式**：自动记录解压链路（每层格式 / 伪装格式 / 命中密码），下次同来源一键按链路解压
- **每层预处理**：名称清洗（非法字符 / 超长路径）+ 自动剔除完全重复文件
- **磁盘空间预检查**、**长路径支持**（Win32 直通）、**DPI 自适应**
- **中途取消**：立即终止正在运行的 7-Zip / WinRAR 进程，原始文件保留
- 成功后可选彻底清理原始分卷与中间压缩包

## 界面

- 选项卡结构：**解压 / 工作流 / 设置**
- 密码管理在主界面右侧，删除/清空有确认
- 深色 / 白色主题一键切换

## 环境要求

- Windows 10 / 11 x64（.NET Framework 4.8 系统自带，零依赖）

## 从源码构建

需要 .NET SDK 8（可编译 net40 目标）：

```powershell
dotnet build src/sz333-tool.csproj -c Release
```

产物位于 `src/bin/Release/net40/sz333解压工具.exe`。
7-Zip 引擎（7z.exe / 7z.dll，LGPL）作为嵌入资源随 exe 分发。
